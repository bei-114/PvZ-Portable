# v8 关卡编辑器、双选关与新挑战

## 不改 JSON 也能做关卡

主菜单点「自定义关卡」，再点「关卡编辑器」。编辑器只在主菜单开放，不在正在战斗的棋盘上重载规则。

1. **关卡**：填写名称，用阳光按钮设置初始阳光；默认草稿已经包含一波普通僵尸，可直接保存试玩。
2. **波次**：切换当前波，新增、复制、删除、前移或后移。时间是“这一波开始前等待多久”，可按1秒或5秒调整。
3. **敌人**：每波由一个或多个出怪组组成。选择类型、数量和行；“自动”会按累计出场数轮换五行，而不是把所有敌人挤在一行。
4. **我的关卡**：浏览、编辑、复制和删除自己保存的关卡。
5. **保存**会立即更新选关目录，不必重启；**另存副本**生成新的稳定ID，不覆盖原关；**保存并游玩**会先确认，再保存并开始。

选择内置关卡后点「编辑 / 复制」，得到独立副本。不会改写推荐内容包或原版冒险/生存关。

### 防止误操作

- 有未保存修改时，离开、新建或换草稿前会询问；取消后草稿保留。
- 覆盖自己的已保存关卡、删除玩家关卡均需确认。
- 试玩仅替换上一个**自定义关卡检查点**，不会改冒险和生存进度。
- 名称、波次、出怪组、总数量或依赖无效时不会保存；错误后草稿仍在，可继续修改。
- 缺少模组的旧玩家关卡不会静默删除，仍可进入编辑器修复敌人类型。

### 当前编辑范围

- 日间五行草坪，初始阳光0..9990。
- 玩家库最多32关，每关1..30波，每波最多12个出怪组、合计最多50只。
- 每组1..50只，行可为自动或第1..5行；波前间隔1..60000tick，100tick为游戏内1秒。
- 敌人选择包括安全的陆地原版类型及已启用的自定义类型；不提供僵王、水生、蹦极或关联载具的任意拼装。
- 此版是**波次关卡编辑器**，不是任意脚本执行器，也不是地图地形或预置植物编辑器。

玩家文件位于应用数据目录下独立的 `playerlevels`，不混入只在启动时扫描的 `mods`。文件使用稳定的 `player.*` ID。保存采用临时文件/备份重命名及失败回滚；路径、符号链接、大小、重复ID和结构均检查。中断事务残留会保留并诊断，不擅自删除恢复材料。它不是针对同一用户权限下并发恶意文件替换的操作系统级隔离沙箱。

## 两种选关方式

- **详情视图**：一关一页，阅读完整玩法说明、初始阳光和波数。
- **卡片视图**：原版小游戏风格的原生卡片陈列，每页六关，可继续翻页浏览。

在选关页点「卡片视图 / 详情视图」即时切换，记住偏好；切换和翻页保留所选稳定关卡ID。两种视图都可进入编辑器、开始新关、继续自定检查点，并显示覆盖提醒。卡片缩略图使用玩家现有原版资源，不打包原版美术。

## 结算不再只有两个出口

结算页显示本关名称、已出波次、有效游戏时间、累计出场数和剩余阳光，并提供：

- 重试本关；
- 胜利后进入目录中的下一关（无下一关时禁用）；
- 返回选关并保留当前选择；
- 返回主菜单。

“已出波次”和“累计出场”不是伪造的击杀统计。有效时间不计暂停、对话和时停；不会发放原版奖杯、商店奖励或改写原版挑战记录。

## 六种新的强敌与克制

启用 `130-carnival-zombies`；四关主题挑战位于 `140-carnival-campaign`，同时还需原 `110-composite-zombies`。不要把所有旧实验平衡包混装。

| 敌人 | 机制 | 应对 |
|---|---|---|
| 南瓜保镖 | 有甲且清醒时，替附近同阵营单位承担40%伤害；保镖不互相递归转伤 | 冰冻/黄油关闭主动护卫，破甲后光环失效，或直接集火保镖 |
| 浓缩咖啡指挥官 | 每500tick给附近同阵营单位250tick的50%加速；不叠加刷成无限速度 | 在号令间隙集火，冰减速仍有效；不是永久提速 |
| 蒜头侧跳者 | 等待400tick后给出80tick箭头预警，再切到相邻行；不向前瞬移 | 贴身阻挡会阻止跳行，冰冻和黄油暂停预备动作，多行火力覆盖 |
| 樱桃快递员 | 靠近植物后启动100tick引信；爆炸造成900近距伤害并消失 | 看见闪烁引信后冰冻/黄油可暂停，提前击杀可拆弹；魅惑后攻击敌人 |
| 阳光扒手 | 只偷附近未收集阳光，每轮最多三枚/75阳光，每只最多携带300；不直接扣银行余额 | 及时收集；击败后通过一次性赏金追回携带阳光；魅惑可帮助自动收集 |
| 反弹高坚果 | 有甲、清醒且就绪时反弹普通直射豌豆；每次损耗有限护甲，80tick反弹冷却 | 抛射、火焰、电能和晶能折射不反弹；冰冻/黄油和破甲均可关闭 |

预警箭头、引信闪烁、护卫/反弹环和携带阳光数字都由实际状态驱动；绘制不推进技能计时。

四关分别为「加班咖啡馆」「蒜香快递」「阳光保卫战」「奇妙防线总动员」。这是高强度机制挑战，建议混合控制、群伤和晶能增幅，不建议只堆单一豌豆射手。

## 存档兼容与测试

复合僵尸侧表在需要预警、携带阳光、加速或反弹弹状态时写v2；仍读取v1，未使用新状态时保留v1布局。倒计时、预警目标行、携带阳光、在途弹与加速剩余时间会保存，读档不会刷新引信或重复领回阳光。

导演检查点v2使用“战斗规则＋当前关内容”指纹；修改无关玩家关卡不会破坏另一关的检查点。旧v1检查点仍按旧算法验证，规则确实改变时仍拒绝混用，不假装能自动恢复所有过渡存档。

```sh
PVZP_MOD_TEST=1 ./build/pvz-portable
bash tests/run-live-regression.sh ./build/pvz-portable ./build custom
PVZP_EDITOR_UI_ONLY=1 bash tests/run-live-regression.sh ./build/pvz-portable ./build editor
bash tests/run-live-regression.sh ./build/pvz-portable ./build editor
bash tests/run-live-regression.sh ./build/pvz-portable ./build levels
```

脚本使用临时HOME，不操作真实玩家存档。UI测试走实际WidgetManager点击、原生输入框和保存确认；试玩测试走自然选卡/首波。标注DIRECT的敌人清理或导演循环只是结束流程验证，不冒充全关人工战斗通关或Android实体手机触控实测。
